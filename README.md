# Mechaneion for Claude Code

Mechaneion's plugin for Claude Code. Connects every session in a repository to its Mechaneion project, says before a turn ends what the session is walking away from, and answers what needs doing next.

Install it for yourself, which turns it on in every repository you open:

```
claude plugin install mechaneion --marketplace Mechaneion/claude-plugin --scope user
```

- Mechaneion: https://mechaneion.com
- Privacy: https://mechaneion.com/privacy

This repository holds the plugin and nothing else.
It is published from Mechaneion's own repository, where every change to the plugin is made, and each publish replaces what is here.
